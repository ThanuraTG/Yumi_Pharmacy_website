# Pharamedic - Pharmacy & Medical React + Tailwind CSS Website

A pixel-perfect, responsive React replica of the **Pharamedic – Pharmacy & Medical Elementor Template Kit** by TBWBthemes.

## 🎨 Design System & Specifications

- **Primary Colors:**
  - Primary Dark Teal: `#2F6C6D`
  - Secondary Charcoal Teal: `#132B2C`
  - Vibrant Button & Accent Teal: `#47A2A3`
  - Soft Mint Accent: `#75C2C3`
  - Background Tint: `#F6F6F6`
  - Muted Text: `#6A6A6A`
- **Typography:**
  - Headings: `Noto Sans` (800 / 700 / 600)
  - Body & Accents: `Noto Sans` & `Lato`
- **Assets:** High-resolution original images, doctor portraits, partner brand logos, and pharmacy graphics extracted directly from the template kit.

## 🚀 Pages & Components Included

1. **Header & Navigation**:
   - Top contact bar with social links, opening hours (`Mon - Sat: 08:00 AM - 09:00 PM`), phone `(555) 987-6543`, and email.
   - Sticky navbar with drop-downs, search modal trigger, shopping bag with dynamic cart badge, and Rx prescription upload button.
   - Mobile responsive drawer navigation.

2. **Homepage**:
   - **Hero Section**: "Delivering Care, One Prescription at a Time" with doctor showcase image, floating experience cards, and star rating.
   - **4 Quick Highlights**: Medicines, Beauty Care, Health Products, Cardio Care.
   - **Who We Are**: "We Are The Most Trusted Pharmacy In This Town" with female pharmacist image and clinical quality badges.
   - **Brand Partners**: 5 certified pharmaceutical suppliers.
   - **CTA Banner**: "Delivering Wellness with Every Prescription".
   - **Our Services Grid**: 6 comprehensive clinical services (Generic Medicine, Health Check & Screening, Vaccination, Medicine Consultation, Doctor Receipt, Pharmacy Store).
   - **The Best Pharmacy Store Banner**: Promotional banner with complete medicine showcase.
   - **Why Choose Us**: 3 feature cards (Honesty & transparency, Expert Pharmacist, Extra Discount) with satisfaction statistics.
   - **Become a Member & Prescription / Refill Form**: Interactive Metform recreation with instant submission feedback.
   - **Meet Our Pharmacists**: Licensed team profiles (Vivienne Lewis, William Painter, Sarah Barnes) with social links.
   - **Testimonials**: Verified customer feedback cards with 5-star rating.

3. **Sub-Pages**:
   - **About Us**: Full company heritage, principles, and facility statistics.
   - **Services & Single Service**: Dedicated appointment booking modal for every service.
   - **Pharmacists**: Complete clinical staff directory.
   - **Membership Program**: Silver, Gold Family, and Platinum membership tiers with full perk breakdown.
   - **Shop Online**: E-commerce catalog with real-time category filtering, pricing, and Add to Cart functionality.
   - **Health Blog**: Medical articles with interactive reading modal.
   - **Contact Us**: Contact details, direct inquiry form, and interactive Google Maps dispensary pin.

4. **Interactive Features**:
   - **Rx Prescription Upload Modal**: Upload JPG, PNG, or PDF prescriptions with express delivery options.
   - **Live Search Modal**: Real-time searching across products, clinical services, and blog articles.
   - **Slide-out Cart Drawer**: Manage items, increase/decrease quantity, view discounts, and checkout.
   - **Back to Top Floating Button**.

## 🛠️ How to Run Locally

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
